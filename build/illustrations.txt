# Les illustrations de l'application, et d'où elles viennent.
#
#     python build/illustrer.py      télécharge, vérifie la licence, convertit en WebP
#                                    dans img/ et écrit build/illustrations.json
#     node build/construire.mjs      rattache ensuite chaque image à ses fiches
#
# Toutes viennent de Wikimedia Commons et sont dans le domaine public (ou sous
# CC0) : le script refuse toute autre licence.
#
#   = identifiant          le fichier sera img/identifiant.webp
#   commons: Fichier.jpg   le fichier sur Wikimedia Commons, sans « File: »
#   legende: …             ce qu'on lit sous l'image (*italique* permise)
#   credit: …              l'auteur, la date, le fonds — la licence s'ajoute seule
#   pour: fiche, fiche     les fiches où elle paraît, en tête
#   largeur: 520           (facultatif) largeur en pixels, 440 par défaut
#   recadrer: 0 0 1 1      (facultatif) gauche haut droite bas, en fractions
#   page: 7                (facultatif) la page d'un livre numérisé
